# Football League Standings Calculator

A command-line Python application that computes football league standings using the rules of the **1974/75 English First Division** — a **2-points-for-a-win** era where teams were separated by **goal average** (the ratio of goals scored to goals conceded) rather than modern goal difference.

The tool reads match results (fixtures) from a CSV file, crunches each team's season statistics, ranks the table by points → goal average → goals scored, and writes the finished standings to a second CSV file.

## Introduction

Manually maintaining a league table across a 42-game season is tedious and error-prone. This project automates the bookkeeping: record each fixture once, and the application produces an accurate, correctly-ordered table every time.

It is built around the scoring and tie-breaking rules actually used in the English First Division for the 1974/75 season, so it doubles as a small historical league simulator.

## Features

- **Fixture-driven CSV input** — log every match with its match week, e.g. `1,Arsenal,Liverpool,2,0`.
- **CLI I/O contract** — `--input` / `--output` file flags plus `-` for stdin/stdout, so the tool slots into Unix pipelines.
- **Full team statistics** — automatically tallies played, won, drawn, lost, goals scored, goals conceded, goal average, and points for every team.
- **Historically accurate ranking** — sorts by **Points → Goal Average (GF/GA) → Goals Scored** exactly as applied in 1974/75.
- **Team-name normalisation** — `Derby Country`, `Carslie`, `WestHam` or `Burnely` are folded into their canonical clubs (case/whitespace-insensitive), so one club can never split into two table rows.
- **Visible failures** — malformed rows are reported with line number and reason; by default the tool warns and continues, and `--strict` aborts with exit code 1.
- **Zero dependencies** — uses only the Python standard library (`argparse`, `csv`, `dataclasses`, `io`, `os`, `sys`, `typing`).

## Rules & Ranking

This implementation follows the 1974/75 English First Division regulations:

| Result | Points |
| ------ | ------ |
| Win    | 2      |
| Draw   | 1      |
| Loss   | 0      |

When two or more teams are level on points, they are ordered by:

1. **Goal Average** = `goals scored ÷ goals conceded` — higher is better.
   **0-conceded policy**: a team that has conceded 0 goals (including a 0-0
   record) is treated as having an **infinite** average and ranks above any
   finite ratio.
2. **Goals Scored** — higher is better.
3. **Team name** — alphabetical. This is a deterministic **display-order
   fallback only**; it is not part of the league's ranking rules.

## Installation

### Prerequisites

- **Python 3.10 or newer** (the code uses modern type-hint unions like `str | None`). It was developed and tested on **Python 3.14**.
- No third-party runtime packages are required.

### Setup

```bash
# 1. Clone or download the repository, then open a terminal in it
cd Football-League

# 2. (Recommended) Create and activate a virtual environment
python -m venv .venv

# Windows:
.venv\Scripts\activate
# macOS / Linux:
source .venv/bin/activate

# 3. Install the test framework (only needed for running the test suite)
pip install pytest
```

## Usage

### Command-line interface

```
usage: football-league [-h] [-i PATH] [-o PATH] [--strict]
```

| Option | Description |
| ------ | ----------- |
| `-i, --input PATH` | Fixtures CSV to read. Use `-` for **stdin**. Defaults to `data/input.csv`. |
| `-o, --output PATH` | Standings CSV to write. Use `-` for **stdout**. Defaults to `data/output.csv`. |
| `--strict` | Abort with exit code 1 on any malformed row or unknown team name. Default: warn and continue. |

### Input format

`data/input.csv` holds one fixture per row. Either of two schemas is accepted
(one per file):

```csv
# 5 columns — with match week (default for this project)
Match Week,Home Team,Away Team,Home Score,Away Score
1,Derby County,Liverpool,2,0
1,Arsenal,Derby County,1,1

# 4 columns — legacy format without a match week
Home Team,Away Team,Home Score,Away Score
Derby County,Liverpool,2,0
```

- A labelled header row is optional and skipped; blank lines are ignored;
  quoted fields (e.g. a team name containing a comma) are parsed correctly.
- Team names are **normalised** before counting: case and spacing are
  collapsed, and known spelling variants are folded into the canonical club
  (`Derby Country` → `Derby County`, `Carslie` → `Carlisle United`,
  `WestHam` → `West Ham United`, `Burnely` → `Burnley`,
  `Queen Park Rovers` → `Queens Park Rangers`, …).
- Names that do not resolve to one of the 22 registered clubs are listed on
  standard error (a warning by default, an abort in `--strict` mode).

### Run it

```bash
# default file-based run: reads data/input.csv, writes data/output.csv, prints table
python main.py

# explicit files
python main.py -i fixtures/season.csv -o fixtures/table.csv

# Unix pipelines: read from stdin, write to stdout
cat data/input.csv | python main.py -i - -o -
python main.py -o - < data/input.csv     # macOS | Linux | Windows PowerShell

# validate a fixtures file without writing (strict mode, exit code 1 on problems)
python main.py -i fixtures/season.csv -o - --strict > /dev/null
```

### Strict vs lenient

By default the tool **warns and continues**: a malformed row is skipped, its
line number and reason are printed to stderr, and the remaining fixtures are
processed. Run with `--strict` to fail fast instead — the process exits with
code 1 and lists every problem, so scripts can rely on it. Malformed rows are
never silently dropped in either mode.

### Output

The standings are written to `data/output.csv` and echoed to standard output:

```csv
Team,Played,Won,Drawn,Lost,Goals Scored,Goals Conceded,Goal Average,Points
Arsenal,4,2,1,1,9,4,2.25,5
Derby County,4,2,1,1,5,6,0.8333333333333334,5
Liverpool,4,1,0,3,4,8,0.5,2
```

Note how **Arsenal** ranks above **Derby County**: both have 5 points, so goal
average decides it (`2.25 > 0.83`). A team that has not conceded yet ranks with
an `inf` goal-average column.

## Testing

The pytest suite (58 tests) covers:
- the 1974/75 rules — points, goal average, goals-scored ranking;
- team-name normalisation and the 22-club registry;
- row-level error reporting and strict/lenient loading behaviour;
- edge cases — exact ties, quoted and whitespace-variant names, duplicate
  fixtures, malformed headers, the 0-0 goal-average policy;
- an **acceptance test** that loads `data/input.csv` and asserts the exact
  week-10 standings for all 22 clubs.

```bash
python -m pytest tests/ -v          # or: pytest tests/
```

Expected: all tests pass. For example:

```
tests/test_unit_team_stats.py::TestAddLoss::test_loss_does_not_reset_points PASSED
tests/test_unit_league_table.py::test_to_csv_header_column PASSED
```

## Future Improvements

- **Per-week snapshots** — `--week N` to print the table as of a specific match week (the match-week data is already captured).
- **Position tracking / form guide** — record each club's position week by week and show recent form (last 5 results).
- **Head-to-head tie-breaker** — a configurable option mirroring modern league tie-breaking rules.
- **Additional point systems** — support 3-points-for-a-win leagues (points are already `WIN_POINTS` / `DRAW_POINTS` named constants).
- **Full 1974/75 dataset** — bundle all 42 match weeks and reproduce the authentic final table.
- **Packaging** — turn the project into an installable CLI package with a `football-league` console entry point.
